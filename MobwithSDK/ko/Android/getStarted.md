# Getting Started <!-- {docsify-ignore} -->

MobWith SDK를 Android 앱에 연동하기 위한 지원 환경, 최신 버전, 연동 순서를 안내합니다.

## 지원 환경

| 항목 | 요구 사항 |
|---|---|
| Minimum SDK Version | Android 23 |
| Compile SDK Version | Android 34 |
| Build Tool | Android Studio |
| AndroidX | 사용 권장 |

## 최신 버전

| 최신 버전 | 설치 방법 |
|---|---|
| 1.0.112 | [SDK Installation](/Android/installation.md) |

버전별 변경 내역은 [History](/Android/history.md)를 참고 바랍니다.

## 지면번호 / App Key

외부 미디에이션 SDK 사용에 필요한 App Key 및 지면번호는 별도로 안내된 값을 이용하시면 됩니다.

!> 일부 App Key와 지면번호는 앱의 Bundle ID 등에 영향을 받을 수 있으니 주의 바랍니다.
