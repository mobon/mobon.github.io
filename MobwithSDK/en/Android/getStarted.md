# Getting Started <!-- {docsify-ignore} -->

This page describes the supported environment, latest version, and integration steps for adding the MobWith SDK to your Android app.

## Supported Environment

| Item | Requirement |
|---|---|
| Minimum SDK Version | Android 23 |
| Compile SDK Version | Android 34 |
| Build Tool | Android Studio |
| AndroidX | Recommended |

## Latest Version

| Latest Version | How to Install |
|---|---|
| 1.0.111 | [SDK Installation](/Android/installation.md) |

For the change history of each version, please refer to [History](/Android/history.md).

## Placement Number(Unit ID) / App Key

For the App Key and placement numbers required to use external mediation SDKs, please use the values provided to you separately.

!> Note that some App Keys and placement numbers may be affected by the app's Bundle ID, etc.
